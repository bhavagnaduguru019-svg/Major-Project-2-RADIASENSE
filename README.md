## 1. Overview & Project Description

**RADIASENSE** is a state-of-the-art full-stack AI medical imaging analysis platform designed to assist researchers and biomedical engineering students in exploring computer vision methodologies in diagnostic radiography. 

The platform supports multi-modal image analysis:
- **Chest X-Ray Classification**: Detects potential pulmonary abnormalities (Normal vs. Abnormal) using deep convolutional neural networks.
- **Brain MRI Classification**: Differentiates between four brain MRI diagnostic categories (`glioma`, `meningioma`, `pituitary tumor`, and `no_tumor`).
- **Explainable AI (XAI)**: Generates Grad-CAM (Gradient-weighted Class Activation Mapping) visual heatmaps and blended overlays to highlight anatomical regions influencing the deep neural network's predictions.
- **Automated Clinical Research Reports**: Generates downloadable PDF research reports with metadata, prediction metrics, class probabilities, and high-resolution Grad-CAM visual evidence.
- **Historical Analysis & Auditing**: Stores analytical histories and model evaluation metrics with full search, filtering, and inspection capabilities.

## 2. Key Features

- **Multi-Modal Deep Learning**:
  - ResNet-50 and VGG-16 backbone architectures with customized classification heads.
  - Transfer learning checkpoints with optional weights fine-tuning.
  - Dynamic fallback to demonstration mode when external weights are absent.
- **Explainable Artificial Intelligence (Grad-CAM)**:
  - Gradient activation tracking on the final convolutional layers (`layer4` for ResNet50, `features.28` for VGG16).
  - High-resolution heatmap rendering with Jet colormap projection and alpha-channel blending.
- **High-Performance Asynchronous Backend**:
  - Built on FastAPI with asynchronous request processing.
  - SQLAlchemy 2.0 ORM with SQLite backend for zero-config persistence.
  - Streaming file validation, size constraints (max 20MB), and sanitized storage.
- **Cyber-Medical UI / UX**:
  - React 18 single-page application built with Vite and TailwindCSS.
  - Dark-mode glassmorphic theme with neon cyan and electric violet accents.
  - Interactive interactive charts (Recharts) for class distributions, confusion matrices, and ROC curves.
  - Real-time drag-and-drop file upload with preview and animated analysis progress.
- **Research Reporting**:
  - Structured PDF report compilation with ReportLab.
  - Includes patient identification tags, confidence breakdowns, model parameters, and embedded visual artifacts.

## 5. Step-by-Step Installation

### Clone the Repository
```bash
git clone https://github.com/your-org/radiasense.git
cd RADIASENSE
```

### Backend Setup
1. Create and activate a Python virtual environment:
   ```bash
   # Windows PowerShell
   python -m venv venv
   .\venv\Scripts\Activate.ps1

   # Linux / macOS
   python3 -m venv venv
   source venv/bin/activate
   ```

2. Upgrade package manager and install dependencies:
   ```bash
   python -m pip install --upgrade pip
   python -m pip install -r requirements.txt
   ```

3. Initialize local directories and demo synthetic samples:
   ```bash
   python create_samples.py
   ```

### Frontend Setup
1. Navigate into the frontend directory:
   ```bash
   cd frontend
   ```

2. Install npm dependencies:
   ```bash
   npm install
   ```

3. Return to the root directory:
   ```bash
   cd ..
   ```

## 7. Model Training Instructions

RADIASENSE includes dedicated training scripts with learning rate scheduling, validation checkpoints, and evaluation metrics logging.

### Training the Chest X-Ray Model
Run the X-Ray training pipeline:
```bash
# Train ResNet-50 on Chest X-Ray
python -m ml.xray.train --arch resnet50 --epochs 25 --batch-size 32 --lr 1e-4 --data-dir data/xray

# Train VGG-16 on Chest X-Ray
python -m ml.xray.train --arch vgg16 --epochs 25 --batch-size 16 --lr 5e-5 --data-dir data/xray
```

### Training the Brain MRI Model
Run the MRI multiclass training pipeline:
```bash
# Train ResNet-50 on Brain MRI
python -m ml.mri.train --arch resnet50 --epochs 30 --batch-size 32 --lr 1e-4 --data-dir data/mri

# Train VGG-16 on Brain MRI
python -m ml.mri.train --arch vgg16 --epochs 30 --batch-size 16 --lr 5e-5 --data-dir data/mri
```

Trained weights are automatically saved to `models/xray_resnet50.pth`, `models/mri_resnet50.pth`, etc., and evaluation metrics are written to `models/model_metrics.json`.

## 9. API Reference

### Health & Diagnostics
- `GET /` — API root, status, and legal medical disclaimer.
- `GET /api/health` — System status, database health, and loaded model weights.

### Analysis & Inference
- `POST /api/analyze/xray`
  - **Payload**: `multipart/form-data` with `file` (image) and optional `model_name` (`resnet50` | `vgg16`).
  - **Returns**: `AnalysisResponse` with prediction, confidence, class probabilities, and base64 Grad-CAM images.
- `POST /api/analyze/mri`
  - **Payload**: `multipart/form-data` with `file` (image) and optional `model_name` (`resnet50` | `vgg16`).
  - **Returns**: `AnalysisResponse` with 4-class probabilities and Grad-CAM visualization.

### Historical Records
- `GET /api/history`
  - **Query Params**: `page` (default 1), `limit` (default 20), `type` (optional filter `xray` | `mri`).
  - **Returns**: Paginated list of past analyses.
- `GET /api/history/{analysis_id}`
  - **Returns**: Detailed analysis record with image references and notes.
- `DELETE /api/history/{analysis_id}`
  - **Returns**: Confirmation of deletion.

### Metrics & Dashboard
- `GET /api/dashboard`
  - **Returns**: Overview statistics (total scans, modality breakdown, 7-day volume trends, recent activity).
- `GET /api/models/metrics`
  - **Returns**: Model performance benchmarks (Accuracy, Precision, Recall, F1-Score, ROC-AUC).

### Reports
- `POST /api/reports/{analysis_id}`
  - **Returns**: Generates clinical research PDF report and returns file path and base64 data.
- `GET /api/reports/{analysis_id}/download`
  - **Returns**: Direct PDF file stream download.
